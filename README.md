### About me

Developer from Barcelona working across **full-stack development and IT operations**. As part of an IT team, I helped deploy and support the device fleet for large-scale events like **Formula 1** and **MotoGP**.

Off the clock I build my own things: web apps, home automation, electronics and a fair share of 3D-printed hardware. What I enjoy most are the problems that sit **between software and the physical world**.

### What I'm working on

- **Umbra** — an edge computer-vision platform for small industry (my own product, in development).
- **Casa** — a TypeScript home-automation system running on my homelab, integrated with Home Assistant.
- **RetroVault** — a Catalan retro-hardware platform: guides, marketplace and collection tracker → **[retrovault.cat](https://retrovault.cat)**
